# Cloudform - Survey Builder

A modern survey builder prototype for creating and managing customer surveys. Built with React and Tailwind CSS in a single HTML file for easy deployment.

## Features

- **Visual Survey Builder**: Create surveys with an intuitive drag-and-drop interface
- **Multiple Question Types**: Support for text, multiple choice, rating scales, and more
- **Real-time Preview**: See your survey as you build it
- **Export Options**: Export surveys in multiple formats
- **Responsive Design**: Works across desktop, tablet, and mobile
- **Configurable Theming**: Easy to adapt to different visual systems

## Tech Stack

- React
- Tailwind CSS
- Babel
- Single-file HTML deployment

## Why this exists

This project explores low-friction form authoring, reusable question patterns, and how small tools can make customer research operations easier to scale.

## Privacy

All survey data is stored locally in the browser unless a backend is added.
